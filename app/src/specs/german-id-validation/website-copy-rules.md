# Website Copy Rules

## Required Result Banner

Use this near every result:

`This tool checks public document-field consistency only. It is not official authenticity, identity, status, loss/theft, or entitlement verification.`

## Allowed Result Labels

Use:

- `Public fields consistent`
- `Public rule failed`
- `Not checked locally`
- `Authority verification required`
- `Source-backed date plausibility`
- `MRZ consistency check`
- `Exchange-deadline plausibility`

## Blocked Result Labels

Do not use:

- `Valid document`
- `Verified identity`
- `Authentic`
- `Genuine`
- `Officially checked`
- `Safe to accept`
- `Not lost or stolen`
- `Holder may drive`
- `Current entitlement confirmed`

## Family-Specific Copy

Identity card:

- Allowed: `TD1 MRZ check digits match.`
- Allowed: `Visible serial and MRZ document number are consistent.`
- Blocked: `The identity card is genuine.`

Passport:

- Allowed: `TD3 MRZ check digits match.`
- Allowed: `Visible serial and MRZ document number are consistent.`
- Blocked: `The passport is travel-valid.`

Driving licence:

- Allowed: `The card validity date is within the 15-year public limit.`
- Allowed: `The exchange deadline is plausible under FeV Anlage 8e.`
- Allowed: `Field 5 is not checksum-validated because no public algorithm is implemented.`
- Blocked: `The holder is allowed to drive.`
- Blocked: `The licence number is authentic.`

## Source Drawer Copy

Use:

`Sources explain the public rule used by this check. They do not prove this specific document was issued or is currently valid.`

## Footer Copy

Use:

`For official verification, use the relevant German authority, register, chip/certificate, or competent inspection workflow.`
